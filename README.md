# Cozy Cabin v0.2
A lightweight, no-build vertical slice for the Cozy Cabin simulator.

## Controls
- Mouse/touch: choose a hotspot
- Keyboard: arrows or WASD choose, Enter/Space interacts, Escape/Backspace returns
- Gamepad: D-pad chooses, A interacts, B returns

## v0.2
- controller + keyboard navigation
- persistent focus treatment for couch/TV play
- warmer room-wide fire flicker
- reduced-motion support
- kept the implementation intentionally dependency-free for Raspberry Pi/browser performance

Open `index.html` in a browser. Audio and dedicated close-up interactions are intentionally next; audio assets should be licensed/owned rather than embedded from random web sources.
